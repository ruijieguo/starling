## 0. 这份预注册要回答什么

前提核验能否**在不伤害可答题的前提下**减少「前提半真诱答」。两个方向必须同时测：

- **它要修的**：弃答题上，开启核验后错误作答减少；
- **它可能伤的**：可答题上，核验把真有答案的题判成 unsupported，模型因此不答或答偏（过度弃答）。

只报前者等于只报收益。

### 3.1 公共随机数：C 臂何时复用 B 臂

C 臂的作答提示 = `apply_support_verdict(B 臂提示, 问题, 判定)`。当判定为 supported 或判定失败
（fail-open）时，该函数返回与 B 臂**逐字节相同**的提示——此时机制对这道题没有任何作用。

**这类题 C 臂直接复用 B 臂的答案与两次判分**，不重新生成、不重新判。只有提示被改写的题
（判定 ok 且为 unsupported）才为 C 臂单独生成答案、单独判两次。

理由：同一提示下重新生成只会注入生成噪声与裁判噪声，与机制无关。冻结前的检验力核算（§10 修订 2）
表明，若每题都独立重生成，即便真实伤害为 0，S3 的上界也会落在约 +3.8pp，超过 +3pp 门槛——
无害的机制会被判为有害。复用是无偏的（同一提示的答案分布相同），且只让机制真正起作用的题贡献差值。

逐题记录 `reused`（布尔）与提示是否逐字节相同的校验，供复核。

## 5. 度量

裁判：官方 `unified_llm_judge_base_prompt`（sha256 `593373c6…`），**每条记录判两次取平均**
（依据 `2026-10-23-judge-variance-audit.md`：单次判分 sd 0.099，每格 n=12 时噪声大于多数效应）。

- **M1 弃答错误率**：弃答题上，两次判分平均 < 1.0 的比例（C 臂、B 臂各算）。
- **M2 可答题低分率**：可答题上，两次判分平均 < 0.5 的比例（C 臂、B 臂各算）。
- **M3 核验判定分布**：C 臂中判为 unsupported 的比例，按弃答/可答分列。这是**确定性**
  指标（判定只调一次、记录原文），用来解释 M1/M2 的变化从哪里来。
- **M4 可答题均分**：C 臂与 B 臂的配对差。
- **M5 判定失败率**：判定调用失败或不可解析的比例（fail-open，按生产行为**不重试**）。
  **M5 > 5% 时结果标为「降级」，不作决定**——大量 fail-open 会把 C 臂拉回 B 臂，使结论偏向无效。

「可答题」= abstention 以外的 9 种能力。§4 的题数（58 / 522）是按每会话 20 题估算的，实际以拉取后
的题目为准并在结果中报告。

## 6. 判据

方法（冻结）：
- 单臂比例：Wilson 95%。
- S2：McNemar **精确**单侧检验（不一致对上的二项检验，H1：B 错 C 对的对数 > B 对 C 错的对数）。
- S3、S4：按题配对 bootstrap，5000 次重采样，种子 20261023；「上界」取 97.5 分位，「下界」取 2.5 分位。

| 编号 | 条件 | 含义 |
|---|---|---|
| **S1** | M1(C) Wilson 上界 ≤ **15%**（n ≈ 58，即错误 ≤ 3 题） | 弃答问题被实质修复 |
| **S2** | McNemar 精确单侧 p < 0.05（至少需 5 对不一致且全部有利） | 改善来自核验，不是题目本身变简单 |
| **S3** | M2(C) − M2(B) 的 bootstrap 上界 ≤ **+3pp**（n ≈ 522） | 过度弃答增加不超过 3 个百分点 |
| **S4** | M4 的 bootstrap 下界 ≥ **−0.02** | 可答题均分不实质下降 |

描述性（不参与决定）：M1(C) 是否满足阶段 B 的 C3 门槛（Wilson 上界 ≤ 25%）。这回答
「lane + 核验能否过阶段 B 当初没过的那道线」，但阶段 B 的数据已用掉，这里只作参照。

**决定规则：**
- **S1、S2、S3、S4 全部成立** → 核验可以随 lane 一起开启（lane 本身是否开启仍由阶段 B 结论决定；
  本次通过只意味着「若开启 lane，应同时开启核验」）；
- **S2 不成立** → 核验无效，保持关闭；
- **S3 或 S4 不成立** → 核验有害，保持关闭，即便 S1/S2 成立；
- **只有 S1 不成立**（改善真实但幅度不够）→ 保持关闭，结论记为「方向成立、幅度不足」。

## 8. 已知偏差（跑前写明）

1. 判定与作答同模型：核验可能与作答共享同样的盲点。换模型判定是另一个设计，不在本次。
2. 右脑只抽 user 话轮（同阶段 B）。
3. 每轮多一次 LLM 调用：C 臂的输入 token 约为 B 臂的 2 倍（判定提示含完整 context_pack）。
6. 复用设计下，被改写的题只有一次 B 生成与一次 C 生成：这部分题的差值仍含生成噪声，无法与机制效应分离。
   这是保守方向（噪声使 S3/S4 更难通过）。
4. 裁判与作答同模型，与论文裁判不同，数字不与论文表直接可比。
5. 29 个会话的类别分布未看过；若严重偏斜（如全是 Coding），结论不外推到其他类别。
