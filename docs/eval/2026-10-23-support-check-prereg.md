## 0. 这份预注册要回答什么

前提核验能否**在不伤害可答题的前提下**减少「前提半真诱答」。两个方向必须同时测：

- **它要修的**：弃答题上，开启核验后错误作答减少；
- **它可能伤的**：可答题上，核验把真有答案的题判成 unsupported，模型因此不答或答偏（过度弃答）。

只报前者等于只报收益。

## 3. 臂

每题四臂，同一个库、同一次检索：

| 臂 | lane | 核验 |
|---|---|---|
| A | 关 | 关 |
| B | 开 | 关 |
| **C** | 开 | **开** |
| D | 关 | 开 |

主比较是 **C vs B**（lane 开启时核验的增量）。D vs A 用来看核验在没有原文时是否有害。

**判据只用 B、C 两臂。** A、D 只服务描述性分析；若按 §9 精简方案执行，A、D 不跑，
不影响任何判定。

## 5. 度量

裁判：官方 `unified_llm_judge_base_prompt`（sha256 `593373c6…`），**每条记录判两次取平均**
（依据 `2026-10-23-judge-variance-audit.md`：单次判分 sd 0.099，每格 n=12 时噪声大于多数效应）。

- **M1 弃答错误率**：弃答题上，两次判分平均 < 1.0 的比例（C 臂、B 臂各算）。
- **M2 可答题低分率**：可答题上，两次判分平均 < 0.5 的比例（C 臂、B 臂各算）。
- **M3 核验判定分布**：C 臂中判为 unsupported 的比例，按弃答/可答分列。这是**确定性**
  指标（判定只调一次、记录原文），用来解释 M1/M2 的变化从哪里来。
- **M4 可答题均分**：C 臂与 B 臂的配对差。

## 6. 判据

区间一律 Wilson 95%（比例）或配对 bootstrap 95%（均分，按题重采样 5000 次，种子 20261023）。

| 编号 | 条件 | 含义 |
|---|---|---|
| **S1** | M1(C) 上界 ≤ **15%**（n = 58） | 弃答问题被实质修复 |
| **S2** | M1(B) − M1(C) 的配对差 > 0（McNemar 单侧 p < 0.05） | 改善来自核验，不是题目本身变简单 |
| **S3** | M2(C) − M2(B) 的上界 ≤ **+3pp**（n = 522） | 过度弃答增加不超过 3 个百分点 |
| **S4** | M4 配对差的下界 ≥ **−0.02** | 可答题均分不实质下降 |

**决定规则：**
- **S1、S2、S3、S4 全部成立** → 核验可以随 lane 一起开启（lane 本身是否开启仍由阶段 B 结论决定；
  本次通过只意味着「若开启 lane，应同时开启核验」）；
- **S2 不成立** → 核验无效，保持关闭；
- **S3 或 S4 不成立** → 核验有害，保持关闭，即便 S1/S2 成立；
- **只有 S1 不成立**（改善真实但幅度不够）→ 保持关闭，结论记为「方向成立、幅度不足」。

## 8. 已知偏差（跑前写明）

1. 判定与作答同模型：核验可能与作答共享同样的盲点。换模型判定是另一个设计，不在本次。
2. 右脑只抽 user 话轮（同阶段 B）。
3. 每轮多一次 LLM 调用：C 臂的输入 token 约为 B 臂的 2 倍（判定提示含完整 context_pack）。
4. 裁判与作答同模型，与论文裁判不同，数字不与论文表直接可比。
5. 29 个会话的类别分布未看过；若严重偏斜（如全是 Coding），结论不外推到其他类别。
