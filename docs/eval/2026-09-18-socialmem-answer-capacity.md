# SocialMemBench回答容量单变量评测与诊断

2026-09-18已完成733题真实开发评测。唯一变量是回答`max_tokens`从512提高到1024；grounded_v1提示、C++核心、来源、检索、裁判和评分均固定。候选得到345/733＝47.07%，父grounded_v1为332/733＝45.29%，净增13题、+1.77个百分点；自由回答236/581＝40.62%，父为221/581＝38.04%，净增15题、+2.58个百分点。

候选没有通过预注册晋升门槛：33网络5000次bootstrap的差值95%区间为[-0.70,+4.27]个百分点，下界未大于0。1024的观测点估计更高，但尚未证明稳定质量提升；通过门槛的推荐开发配置仍保留为grounded_v1/512。1024-token候选保留为未晋升实验，不改变默认legacy或生产配置。该区间只反映网络重采样，不覆盖重复生成、裁判或服务端变化的不确定性。

## 证据覆盖和机制诊断

召回完全固定。找齐公开锚点的527题由272正确升到285，部分锚点129题36→38，零锚点77题24→22。本轮没有来源覆盖改善；分数变化发生在相同检索输入之后的回答、裁判和可用性环节。公开锚点也不是穷尽性证据，不能以“全锚点”自动断言上下文完整。

固定SHA样本在“新对、退步、全锚点仍错”三个桶各取3题，仅用于非盲的开发诊断，不校分、不估计总体误判率。详细记录见[九题原始样本](../../build/socialmem_20260918_answer_capacity_v2/mechanism-cases.json)、[失败恢复分解](../../build/socialmem_20260918_answer_capacity_v2/posthoc-diagnosis.json)和[逐题复核](../../build/socialmem_capacity_checks/mechanism-review.md)。

- **主体与话语归属错误**：Sana/Dev题把Dev的“checks notes”修辞写成Sana实际查笔记，并用它解释她的实用性；同一Dev在其他会话也使用该修辞。来源已召回，问题在将发言人的旁白误分配给被观察者。
- **已召回互动链遗漏**：Owen题引用了离开标记路线找蘑菇的偏好，却漏用Bernard“需单独许可”和Owen随后反驳的两条来源。Chidi题则漏用Sophia“busy week at the surgery”的工作压力线索，把变化归因于行程物流压力。这些例子需要改善证据选择与互动因果整合。
- **变化边界与参考解释空间**：Kenji本轮回答“无法确定变化”，并非上一紧凑实验的时间方向反转。S3确有植物专业判断，早于S4围栏纠纷；应区分持续提供专业意见与后来更主动澄清的变化，不能把参考答案的触发解释直接当成唯一事实。
- **新对仍可能有局部瑕疵**：Preet样本保留了S1至S4的收藏变化，Marcus搬迁样本保留确认决定、Dev追问和个人原因的链条；但父答案已有部分相同内容，不能全部归功于预算。Marcus/Ana虽获YES，仍将Marcus先前的6am表态误称为“later statement”。裁判YES不等于所有细节无误。
- **主结论与附加推断需分开**：Marcus/Bex的后院与移动暗场主结论有来源，候选也已承认Bex接受变化；但“较近暗场”不必然证明Marcus偏爱后院，Bex接受Bortle 3也不等于始终偏爱最远暗空。Jess的“proper conversations”引语真实，候选却把解释重心移到她事前预料嘈杂，超出了明确表达。此类题同时包含附加推断风险与评分疑点。

裁判原始HTTP响应保留reasoning_content，但仍按原YES/NO协议计分。后续评分审计需要独立标签与更广样本，不能凭这9题改分，也不能用评分疑点解释全部退步。
