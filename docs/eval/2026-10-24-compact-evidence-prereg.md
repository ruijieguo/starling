# 压缩证据块评估预注册

**状态：已冻结（2026-10-24，用户批准预算、选定非劣界之后，任何 C 臂作答之前）。** 冻结后不得在看到结果后修改；修订按 §6 追加。

## 0. 目的与口径

先引用后作答（#98）让输出 token 的中位数从 108 涨到 457，约 4.3 倍；按每次调用的总 token 算，约多 9%，因为 prompt 约 7.4K，占了大头。
**主要代价是延迟**：用户要等模型写完一段用户看不到的证据块，才能看到回复的第一个字。

本次改动只改指令措辞：每条证据只写日期和陈述相关事实的那几个词（≤ 15 词），不再整行抄录，条数不设上限。
**目标是在不损失质量的前提下削减证据块长度**，因此这是一个**非劣检验**，不是优效检验。

**数据**：BEAM-1M 全量。验收时它已经用过一次，但本次的比较对象是同一批数据上已有的 G 臂。被测的是「压缩是否伤害质量」，
不是重新估计先引用后作答的效应。由于 G 臂的效应量已经在这批数据上算过，**本次结论不能外推为新的效应量**。

**设计依据**：只看了开发集 BEAM-500K 7–35 的证据块结构（中位 6 行、每行约 163 字符、占 completion 的 67%）。BEAM-1M 上只看了
token 的汇总统计，没有看任何作答或证据内容。

## 1. 臂

| 臂 | 来源 |
|---|---|
| B | 复用验收数据 |
| G | 复用验收数据（原版指令） |
| **C** | **新跑**：压缩版指令（`feat/compact-evidence` 分支） |

- 总结类请求被豁免（#99/#100），这些题的 C 等于 B，直接复用。实际需要新跑 629 题。
- 一致性闸：C 与 G 的 context_pack 逐字节相同；C 的提示去掉指令后，与 B 的提示逐字节相同。
- 作答参数与验收一致：`max_tokens=4096`、temperature 0、thinking disabled。

## 2. 度量

裁判使用官方 rubric 提示，C 臂每条判两次取平均。

- **C1 质量非劣（主）**：630 道可答题上 C − G 的配对差，按题 bootstrap 95%（5000 次，种子 20261024）。
- **C2 长度**：C 臂 completion 中位数，与 G（457）、B（108）对比。
- **C3 弃答**：70 道弃答题的错误数，C 对 G。
- **C4 无回复轮**：证据块未闭合的比例。
- 描述性：按能力统计 C − G；C − B 的配对差。

## 3. 判据

| 编号 | 条件 | 依据 |
|---|---|---|
| **K1** | C1 的 bootstrap **下界 ≥ −0.025** | 非劣界：用户 2026-10-24 选定（草稿原为 −0.015） |
| **K2** | C 臂 completion 中位数 ≤ 0.6 × G | 压缩至少要达到这个幅度，才值得换掉原版 |
| **K3** | C 臂弃答错误 ≤ G 臂弃答错误 + 3 | 与验收的 H2 同一口径 |
| **K4** | C 臂无回复轮 ≤ 2% | 与验收的 H3 同一口径 |

- 全过 → 用压缩版替换原版：开 PR 合入 main。
- 任何一条不过 → 不替换，结果照实记录，**不改措辞重跑**。

**检验力**：配对差的 SE 约为 0.0105。若真实差为 0，K1 的通过概率约 65%。草稿中的 −0.015 在真实差为 0 时大概率不过，因此放宽。
**代价**：最坏情况下，可以让出约 0.025 的质量，与先引用后作答的全部收益（+0.022）相当。用户知情并接受。

## 4. 预算

| 阶段 | 估算 |

| C 作答（629 题 × 约 7.6K prompt + 约 0.45K completion） | 4.8e6 |

用户 2026-10-24 批准。硬上限 1.2e7，每阶段开始前检查「已花 + 本阶段估算」。

## 5. 已知偏差

1. BEAM-1M 已用过一次，G 臂的效应是在这批数据上估计的。
2. 裁判与作答是同一个模型。
3. 「≤ 15 词」是按开发集每行约 163 字符估出来的经验值，没有在开发集上调过。

## 6. 修订记录

### 修订 1：K1 只比较非总结题（2026-10-24，写分析脚本时发现，任何 C 臂作答之前）

**问题**：§2 的 C1 写的是「630 道可答题上 C − G」。但 C 臂带 #99/#100 的总结豁免（总结题等于 B），G 臂取自验收，没有豁免。
summarization 上 G − B = −0.112，所以把总结题算进去，C − G 会因为豁免自动多出约 +0.112 × 70/630 ≈ **+0.012**。
这个差值与压缩无关，会让 K1 偏宽松。

**处理**：K1 改为在 **560 道非总结可答题**上比较 C − G，界限不变（下界 ≥ −0.025）。含总结题的 630 题数字仍然报告，但只作描述，不参与判定。
修订时还没有任何 C 臂作答，也没看任何结果。

**检验力**：n 从 630 降到 560，SE 约从 0.0105 升到 0.0111；真实差为 0 时，K1 的通过概率约从 65% 降到 60%。
