# 先引用、后作答 BEAM-1M 验收预注册

**状态：已冻结（2026-10-24，用户批准全量规模之后；冻结前只建了 conv1 的库，没有任何作答）。** 冻结后不得在看到结果后修改；
修订按 §8 追加。

## 0. 目的与来源

开发评估（`2026-10-23-grounded-answer-dev-results.md`）在已用过的 BEAM-500K 7–35 上发现：先引用、后作答让可答题
+0.042 [+0.017, +0.066]。这个结果是**事后发现的**，当时的预注册主判据是弃答（没有通过）。本次在**从未用过的** BEAM-1M 上，
**以可答题收益为主判据**做验收，决定这项改动是否上线。

## 1. 被测实现（冻结）

- 代码：`feat/grounded-answer` 分支，`072365e`（包含截断修复）。指令文本 `kGroundedAnswerInstruction` 与开发评估逐字节相同，
  **不做任何改动**。
- 截断语义：证据块未闭合时，按失败轮处理，没有回复；裁判按「无答案」记 0 分（与生产 `converse_commit` 一致）。

## 2. 数据

- BEAM-1M 全部 35 个会话，共 700 题：10 种能力 × 每会话 2 题。其中可答题 630 道（9 种能力），弃答题 70 道。
- 建库代码与 500K 留出集完全相同（`support_check/b1_build.py`），只换数据与库目录（`spike/beam1m/`）。
- 冻结前只看过各会话的规模计数，没有看过任何题面。

## 3. 臂

| 臂 | 提示 |
|---|---|
| B | lane 开，现行 main 的提示（不加证据块指令） |
| G | lane 开，B 的提示 + 先引用后作答指令 |

两臂都在本次新跑：同一个库、同一份 context_pack，参数为 `k_source=30`、`32000`、`tau=0.56`、`recall_k=10`、`AS_OF=2099-01-01`。
作答模型 `deepseek-v4-pro`，thinking disabled，temperature 0。

**作答长度 `max_tokens=4096`**，两臂相同。这与生产 dashboard chat 的默认值一致。开发评估用的是 2048，证据块放不下。

**一致性闸**（逐题检查，两条都过才算这道题有效）：
- G 与 B 的 context_pack 逐字节相同；
- G 的提示去掉证据块指令后，与 B 的提示逐字节相同。

只要有一题不通过，整轮停止，不出数字。

公共随机数：没有 `[SOURCE]` 行的题，G 的提示与 B 完全相同，直接复用 B 的作答和判分。

## 4. 度量

裁判使用官方 rubric 提示（sha256 `593373c6…`），**两臂每条都判两次**，取平均。

- **A1 可答题收益（主）**：630 道可答题上 G − B 的逐题配对差均值，按题 bootstrap 95%（5000 次，种子 20261024）。
- **A2 弃答非劣**：70 道弃答题上的错误作答数（两次判分均值 < 1.0），G 与 B 配对比较。
- **A3 截断**：G 臂证据块未闭合的比例（无回复轮），以及作答撞上 `max_tokens` 的比例。
- 描述性指标：按能力分别列出 G、B 的均分；可答题低分率（< 0.5）的差。

## 5. 判据（决定是否上线）

| 编号 | 条件 | 依据 |
|---|---|---|
| **H1** | A1 的 bootstrap **下界 > 0** | 主判据：收益要可靠为正 |
| **H2** | G 弃答错误 ≤ B 弃答错误 + 3 | 非劣：不允许明显地多编造。开发评估中 G 比 B 少 2 个错误 |
| **H3** | G 臂无回复轮（证据块未闭合）≤ 2% | 生产可用性：用户问了却得不到回复的比例 |

- H1、H2、H3 全过 → 上线：开 PR 合入 main。
- 任何一条不过 → 不上线，分支保留。结果按实际情况记录。

门槛完全依据开发评估的数字与产品要求设定，没有参考 BEAM-1M 的任何作答。

**检验力**：按开发评估的配对差标准差估算，630 题对应的 SE 约 0.011。若真实效应为 +0.042，检验力约 96%；为 +0.03 时约 75%。
+0.042 是事后估计，可能偏高。

## 6. 预算

用户 2026-10-24 追加批准，硬上限 **6.0e7**。按实测单价估算：

| 阶段 | 估算 |
|---|---|
| 建库（35 会话，用户话轮共 8.05M 字符 × 实测 2.23 token/字符） | 18.0e6（其中 conv1 已花 1.11e6） |
| 作答 B + G（700 × 15.4K） | 10.8e6 |
| 判分（700 × 2 臂 × 2 次 × 3.5K） | 9.8e6 |
| 合计 | **约 3.86e7** |

建库与作答都经本地计量代理（`usage_proxy.py`）实测；判分 token 由适配器返回值累计。**每个阶段开始前**检查「已花 + 本阶段估算 ≤ 6.0e7」，
不满足就停下请批。

## 7. 已知偏差

1. 裁判与作答是同一个模型。
2. 右脑只抽取 user 话轮。
3. 指令措辞是在看过 500K 上 B 臂 10 道弃答失败题之后写成的。本次验收正是对此的检验。
4. BEAM-1M 用完后，再没有大的留出池可用。
