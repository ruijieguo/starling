# SocialMemBench R6.2/R6.3：八库基线、配对评测与能力诊断

> **后续结果（R6.4，2026-09-26）**：来源容量20的真实QA已完成，grounded为41→48/133，legacy为37→37/133；可靠性和区间门槛未通过，不晋升。见[最新评测报告](2026-09-26-socialmem-r64-source-capacity.md)。本文保留R6.2/R6.3阶段的原始结论与当时计划。

## 结论

八库建库、266个检索上下文、532个fresh答案及独立核验均已完成。133题开发cohort上，grounded_memory_v1由36/133（27.07%）升至41/133（30.83%），净增5题、3.76个百分点；legacy两臂均为37/133（27.82%）。本轮在来源容量/结构声明混合方式调整后观测到有限收益；单次生成和裁判的波动尚未排除，仍未达到高准确率目标。

本轮不晋升：预注册主指标要求增益至少5个百分点、网络bootstrap区间下界为正、共同正常样本净增为正，且两臂正常比例均至少95%。本轮增益不足5个百分点；grounded两臂正常比例分别94.74%、91.73%，也未达标。不能把旧57题开发轮的8.77/12.28百分点收益直接推广到本次新增133题。

这里的“完成”是评测终态与证据链完整：514/532正常，18项技术失败计错。不是532项全部成功，不是SocialMemBench全量或独立保留集分数。R6.2健康门禁与R6.3核验修复本身不代表语义准确率提升；本表比较的是同一核心、同一数据库上的两个检索配置。

934条真实向量均非零，但27条raw/index余弦低于0.5、4条为负。共线合成fixture已发现重复投影扣减问题；这是待独立修复的C++数值边界，目前没有建立其与本轮QA错误的因果联系。

## 原始案例复核

以下是开发集事后案例，不改原分数、不估计总体裁判误判率。

1. **互动链漏选：Q7_cf13s4c3。** 餐厅话题的3个锚点仅呈现1个，回答声称没有这段餐厅互动；遗漏的互相回避和他人转移话题才是关系判断所需信息。需要以互动链为选择单位，不能只保留孤立的人物话语。
2. **关系推断过强且缺解释机制：Q7_cf13s6c1。** 回答看到Marcus未受邀仍帮Tom搬家，就概括为“深厚信任和长期亲密”；参考要求的共享表格/具体功能协作没有被呈现。应先把行动、触发细节、双方回应连起来，再作有限的关系解释。
3. **状态变化边界未抓准：Q8_d6e7f8a9。** 公开锚点2/2，但回答用早期协助整理装备和后期路线研究来概括主动性，没有突出Session 10未经提示主动提出过夜方案和预留床位这一变化界点。单列时间点不足以替代“之前状态—触发—主动改变—持续验证”的证据结构。
4. **有效改善：Q8_e6f7a8c0。** source10呈现3/3锚点后，将Leo此前忽视拉伸、腿筋问题、新承诺和赛后执行连接起来，原判错变为判对。该例支持完整变化链的价值，不说明所有变化题已经修复。
5. **参考答案裁判的可见性限制：Q7_d7e8f9a003。** source10回答包含主要参考要点，并增加“Reuben推荐食品安全cone 6釉料”这一细节；它确实存在于已选Session 4来源中。裁判只见参考与答案，无法查证额外细节，其返回分析将“不在参考中”视作潜在不等价原因。回答中的“深厚信任”等表述仍可能过强，因此这不是自动改判理由。
6. **混合问题：Q8_d7e8f9a001。** “anagama-adjacent setup”同样确实存在于已选来源，裁判却质疑其未见于参考；同时回答确实未覆盖Reuben对旧群体惯例的说明。这类样本同时含答案覆盖不足与裁判证据可见性问题，不能简单归为模型全错或裁判全错。

本轮保留原裁判、原标签和主分数。未来若增加来源可见的人工或独立诊断，应单列为质量审计，不能替换基准评分后宣称涨分。
