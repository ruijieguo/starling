## 3. 度量

裁判：官方 rubric 提示（sha256 `593373c6…`），**A 臂每条判两次取平均**（B 已判两次）。

- **R1 可答题收益（主）**：522 道可答题上 B − A 的逐题配对差均值，按题 bootstrap 95%
  （5000 次，种子 20261023）。
- **R1u 保守收益**：R1 限于 gold 证据**全部是 user 话轮**的 448 题。理由：右脑只抽 user 话轮
  （阶段 B §7.1），gold 含 assistant 话轮的 74 题（其中 summarization 53）lane 关时结构性拿不到，
  会**高估** lane 增益。两个数字并列报告，R1u 是不受该偏差影响的估计。
- **R2 弃答代价**：58 道弃答题，B 与 A 的错误作答数（两次判分平均 < 1.0），各自 Wilson 95%，
  及不一致对（A 对 B 错 / A 错 B 对）。
- **R3 渲染率**：lane 开时以与 `converse_prepare` 相同的 `PlannerQuery` 调 planner，取
  `source_entries`；至少一条命中 gold 话轮即「已渲染」。C1 = 522 题、C2 = temporal_reasoning 58 题，
  Wilson 95%。**一致性校验**：planner 的 `context_pack` sha 须等于 B 臂记录的 `context_sha`，
  不等则该题记「未渲染」并单列计数。确定性指标，只需查询嵌入。
- 描述性：按能力的 A、B 均分与差值；按 gold 说话人分层的差值。

阶段 B 判据作参照（不作决定）：C1 下界 ≥ 65%、C2 下界 ≥ 55%、C3 上界 ≤ 25%。

## 4. 裁判漂移抽检

B 臂的判分早于 A 臂数小时。按能力分层随机抽 B 臂 20%（116 条，种子 20261023）**再判一次**，
与该条原两次判分均值比较。若漂移均值 |d| > 0.03 **且** bootstrap 区间不含 0：A−B 差值标注为
「含裁判漂移」，补判全部 B 需另行批准（约 6e6）。
