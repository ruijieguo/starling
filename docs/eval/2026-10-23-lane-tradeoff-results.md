## 2. 收益与代价

| | lane 关（A） | lane 开（B） | 差 |
|---|---|---|---|
| **R1 可答题均分**（n = 522） | 0.241 | 0.602 | **+0.361 [+0.326, +0.396]** |
| R1u 只含 user 证据（n = 448） | 0.249 | 0.611 | +0.362 [+0.322, +0.404] |
| **R2 弃答错误**（n = 58） | 2（上界 11.7%） | 10（上界 28.9%） | **+8 题** |
| 全部 580 题均分 | 0.314 | 0.625 | +0.311 |

- **R1u 与 R1 几乎相同**：预注册担心的偏差（右脑只抽 user 话轮，含 assistant 证据的题 lane 关时结构性拿不到）
  没有实质影响。含 assistant 证据的 74 题差值 +0.351，与只含 user 的 +0.362 相近。
- **弃答代价是真的**：不一致对 8:0，即 lane 开让 8 道原本正确弃答的题变成错误作答，没有一道反向变化；
  精确单侧 p = 0.004。
- 按 BEAM 的题型比例（90% 可答、10% 弃答）折算：每 100 题，lane 在可答题上多拿约 **32.4 分**，
  在弃答题上丢约 **1.4 分**。

| 能力 | A | B | 差 |

| preference_following | 0.779 | 0.899 | +0.121 |

收益覆盖全部 9 种可答能力，没有一项为负。preference_following 增益最小，因为右脑语句本身已经覆盖得较好（A 臂就有 0.779）。

**lane 关时右脑单独作答很弱**：可答题均分 0.241，开头即拒答的约占 11%（启发式，lane 开时约 4%）。
这比 500K 会话 1–6 的 lane 关臂（0.341，单次判分）还低。会话 7–35 的语句数也更少（中位 406，1–6 中位约 740），
但会话内并不呈现“语句越少、A 越低”的关系，原因**未验证**。

## 5. 待用户裁定：C3 是否修改

lane 在两个独立数据集上都过不了 C3（100K 8/40、本次 10/58），C1、C2 都过。可选：

1. **修改 C3，带着已知代价开启 lane**：弃答错误率约 17%（上界 29%），换来可答题 +0.36。
2. **维持 C3，lane 保持关闭**：放弃可答题上的 +0.36。
3. **开启 lane，同时在 BEAM-1M 上做下一版弃答修复**：方向是检查答案中关于用户过去的具体事实能否在证据中找到，
   而不是检查问题所问的细节是否被陈述过（后者的失败原因见 `2026-10-23-support-check-results.md`）。
