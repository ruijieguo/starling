## 问题与实现

A 的七条作用域字段错误涉及 17 个候选：原文通过 wire schema，但主作用域不在标记数组中，C++ 来源解析已拒绝。S 在 C++ 共享生成指导中明确非空、唯一、主作用域成员、兼容性、主体及转述归属要求，保留原六例，新增中英各一份“转述＋条件＋关系否定”示例。英文使用轮渡恢复与岛屿参观，中文使用门票与天文馆参观，均为独立编写场景。

核心仍由 C++ 负责：提示、schema、来源解析、HTTP 截止及重试。Python 新增单臂 worker 与隔离进程调度器，只负责配置、样本选择、配对顺序、请求身份、归档和统计。T 显式传入原生 60000/120000 ms；模型 qwen3.7-plus，4096 输出 token，温度 0，零重试。语义准入、回答、裁判、嵌入不在抽取实验中；能力探测包含既有空候选准入协议探测，不对实验来源执行准入。

schema 和 parser 未变：字段结构错误仍整批拒绝，既有语义错误仍按行拒绝，空 statements 合法。生产默认仍关闭语义声明契约、使用 Legacy、没有时间视图；通用默认模型及 60 秒截止未调整。
