# BEAM-500K 小样本诊断：确认作答提示修复的方向

冻结于 2026-10-22，在任何 500K 题目被作答之前。

## 0. 这不是验收

BEAM-100K 的正式验收（`docs/eval/2026-10-22-form-s-stage-b-beam-results.md`）结论是 **C3 未通过、
lane 保持关闭**，那个结论不变。本文档只回答一个问题：

> 把"[SOURCE] 是原话、不是答案"写进提示（commit 2e268c5）之后，**弃答题被相关原话诱答这个
> 失败机制是否减弱**？

**不构成上线授权。** 样本量（12 道弃答题）只够看方向，不够定阈值；任何数值都不得作为 SOTA 或
上线依据。

## 1. 数据（已核实与 100K 无重叠）

- BEAM-500K 的会话 1–6，官方仓库 `chats/500K/<id>`，共 **120 题**（10 能力 × 2 题 × 6 会话）。
- 与 100K 无重叠：topic 层面 n100=20 / n500=35、交集 0；两者的 title 与 subtopic 均不同。
- 产物 `beam500k_n6.json` sha256 `079c0e02…`。
- **必报的采样偏差**：会话 1–5 全是 `Coding`，会话 6 是 `Math`。120 题只覆盖 8 个类别中的 2 个，
  类别结论不可外推。

## 2. 建库与作答

与 100K 验收**完全相同的代码路径与参数**，只换数据：

- 左脑：全量话轮（两种角色），每批一个场景，`audience=[assistant,user]`，
  去掉 `->-> x,y` 后缀，`observed_at` = 该批锚点日期 + 批内序号秒。
- 右脑：**只抽 user 话轮**，生产分块 8000 字符，`thinking_type="disabled"`，`max_tokens=8192`。
- 嵌入：DashScope `text-embedding-v4` / 1024 维。
- 作答：`memory_converse_prepare`（`recall_k=10`、`created_at=2099-01-01`），
  两臂 ON（`tau_source=0.56`、`k_max=200`、预算 8000）/ OFF（不设 lane），
  用生产提示调 `deepseek-v4-pro`，temperature 0，thinking disabled。
- 裁判：官方 `unified_llm_judge_base_prompt` 原文（sha256 `593373c6…`），
  `deepseek-v4-pro`，每条 rubric 单独判 1.0/0.5/0.0 取平均。

## 3. 度量

- **主（诊断对象）**：弃答题（`abstention`，n=12）的**错误作答率** = 得分 < 1.0 的比例，
  口径与 100K 验收的 C3 一致（部分弃答亦算答错）。
- **对照**：同一批题的 **OFF 臂**（不开 lane）错误作答率。100K 上失败全部集中在 ON 臂，
  所以**两臂之差**才是修复是否生效的直接证据，绝对数受样本限制。
- **必须同时报**：C1 证据渲染率（n=108 道带 `source_chat_ids` 的题），确认提示改动没有
  连带压低召回；以及 agent 是否变得过度弃答（ON 臂的**过度弃答**：可答题里答出
  "未提及/不知道" 且得分 < 0.5 的比例）。

## 4. 判读规则（跑前固定）

- 若 **ON 臂弃答错误率显著低于 OFF 臂**（差值 ≥ 2/12 = 16.7pp）且 C1 未见明显下降
  （≥ 100/108）→ 记为"修复方向成立"，据此规划完整的 500K 验收。
- 若 ON 与 OFF 相近，或 C1 明显下降 → 记为"方向不成立"，回到提示设计。
- **无论结果如何，都不在本数据上调阈值或改判据。**
- 不报 p 值、不报置信区间作判定依据（n=12 撑不起）；只报计数。

## 5. 预算

约 6e6 tokens（右脑抽取约 2e6 + 两臂作答 + 逐条 rubric 裁判），在 2026-10-21 批准的
1–2e7 内。嵌入走 DashScope，单独计。
