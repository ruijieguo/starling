## 来源格式与职责

采用 C++ `claim_source_turn_payload(turns_json)` 生成可持久化的版本化 JSON 行：每行前缀 `@starling/source-turn-v1 `，后接一个话轮对象。输入为对象数组，字段仅允许 `speaker`、`text`、`session_id`、`turn_id`、`turn_index`、`observed_at`。前两者为非空字符串；元数据可空，轮次为非负整数。时间允许真实 ISO 秒精度本地时间、Z 或数值时区偏移，校验真实日期与时分秒，但不猜测时区，不追加 Z，不做事件时间换算。未知时间保持 null。

C++ 同时负责格式生成、JSON 转义、元数据验证、UTF-8 字节位置和 payload hash。每个来源单元的 `text` 保留完整编码行，`utterance` 保留解码后的原始话语；换行、分隔符、中文和引号不拆成伪话轮。普通文本与旧 Session 头格式继续兼容。

Python 评测只从已复核 history 按 holder 选择话轮，映射字段并转调原生函数，不自行拼接协议、补全主题或规范化日期。`session_id` 缺失保持 null，`turn_index` 映射原 message_index，真实 turn_id 和 observed_at 直接保留。模型不拥有权威 source_turn 的写入权。字段缺省时由 C++ 生成；字段出现时必须与来源重建结果完整一致，以支持原生回读重放，任何补造或重写都拒绝。

## 时间与来源安全

`source_turn.observed_at` 表示消息观察时间；`source_time` 仍取 Engram 写入时间；`event_time` 只由话语正文的明确事件时间支持。范围、主题、相对时间词及事件时间校验仅检查解码后的话语，不能从元数据日期/说话者字段补证据。具备来源说话者的直接自述不被 said yes 错判为转述。

提取证据、Bus 写入与检索统一调用 C++ 来源解析器。回读时必须重建并匹配 source_turn；篡改时间、说话者、轮次或删除版本化话轮元数据均拒绝。无需数据库迁移，证据保存在已有 semantic_claim_json 与原始 Engram payload 中。

审查边界补充：只有版本化话轮与有效旧 Session 头允许从元数据中分离正文；普通文本即使包含冒号也必须完整参与条件、主题和时间校验，不能将首个冒号前的正文丢弃。直接 Bus 写入与数据库回读也必须使用 C++ 严格 JSON 解析，任何嵌套层级的重复键都拒绝，不得先用宽松解析覆盖后再校验。
