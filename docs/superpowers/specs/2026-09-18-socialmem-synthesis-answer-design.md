# SocialMemBench 单次综合回答设计

按用户持续授权，继续自主诊断、改进和评测。先中文文档，再失败用例，最后实现。保持现有main工作区，不提交、清理或切分支；独立build目录隔离实验。核心能力只在C++实现，Python仅绑定、路由、运行和统计。

## 诊断与选择

已重新核验上一轮3927文件封存：376/733、51.30%，seal=a8fe8bebab8726ef33da4219001ecb0d6917af5376813425d32bf85e2a79b46d。348份既有文档与5份待改源码逐项比对并快照到build/socialmem_synthesis_checks。

上轮357道未得分题含23技术失败；608题命中全部公开锚点，仍有252题技术成功却判错。公开锚点不是完整答案要点清单，不能把全锚点等同于信息充分。新增固定SHA样本12题（Q1/Q7/Q8各三道技术正常且全锚点错误题，以及Q3三道技术正常错误题）显示：拒绝有根据的模式推断；把他人争论错误绑定到一对合作者；把竞争解释成玩笑或把同行解释成导师；变化题遗漏触发条件；多成员问题逐人覆盖不足且被无关细节挤占输出。

比较三条方案：继续扩大检索容量，预计成本增加且不能解决上述语义错误；先做自然语言时间范围硬过滤，当前缺少可靠范围解析，易误删有效回顾证据且影响面大；本轮选择固定全部来源与预算，改进单次回答的证据表示及综合规则。它是可复用的C++证据包与生成政策，不是已验证的事件推理器，不承诺自动判断因果或冲突正确性。上轮退化的额外证据规划不启用。

## C++接口及生成边界

在evidence_answer.hpp/.cpp新增：

- synthesis_source_answer_packet(question, source_block) -> UTF-8 JSON字符串。
- synthesis_source_answer_prompt(question, source_block) -> 单次最终回答提示。

证据包版本synthesis_v1，包含question、sources数组和semantic_verified=false。复用既有C++来源解析器，为每条来源按输入顺序分配1开始的source_id；保留原speaker、session_id、turn_index、observed_at、未知时间说明、其他元数据及完整text。不得根据题号、reference、锚点、正确性或查询类型选择证据。不得去重、合并说话人、重排、截断或凭空生成事件时间。source_id只作为本次包中的位置，不是跨库身份。

空白问题、损坏JSON、非SOURCE行、缺少合法speaker、非字符串text、尾随文本在模型请求前抛invalid_argument；空来源得到空sources，不编造内容。Unicode、引号、换行和伪造分隔符通过JSON转义保留为数据。该接口的前置条件是来源已经过授权与可见性过滤，本身不新增权限能力。

单次综合规则要求：先识别问题的实体、范围和各子问题；在允许范围内区分先前状态、具体触发和后续状态；observed_at表示陈述时间，回顾过去的发言不能自动成为过去发生时的记录；连接提议、回应、修正、限定和反证。允许有原文支持的社会推断，既不要求关系必须被直白宣告，也不把稀疏证据扩大成确定的终身特征。不得把同行支持强化为导师关系、把共同处理别人的争议改写成双方矛盾、把舒适熟悉感等同于没有真实竞争。多成员问题逐人或按相同立场分组覆盖，区分明确偏好、实际行为与未知，不把一次日程冲突当永久偏好。回答优先覆盖关键结论和有区分力的细节，避免重复标题、长引文和总结，不设新的硬字数或语言限制。

这些规则引导LLM解释，不机械校验最终答案语义。测试验证的是数据完整、路由、调用次数与失败边界，真实准确率只能通过冻结评测判断。

## 单次综合回答接口（2026-09-18）

C++在evidence_answer.hpp/.cpp提供synthesis_source_answer_packet与synthesis_source_answer_prompt，复用来源解析器，将已授权的原生SOURCE块转换为synthesis_v1证据包。保留来源顺序、说话人、会话、话轮、陈述时间、未知时间元数据及原文；source_id是包内位置，text是正文保留字段，输入元数据不得占用这两个名称；空白说话人与损坏来源在请求前拒绝。证据包不是权限过滤器，也不补写事件时间或认证答案语义，semantic_verified始终为false。

新提示引导单次模型回答注意问题范围、事件时序、实际触发、回应与反证、推断强度和多成员覆盖；规则没有实现自动语义校验。Python仅暴露接口和路由；synthesis_v1只允许sources召回，自由题一次回答、至多一次原裁判，选择题保持旧提示。旧政策与推荐默认不变。本轮固定上一轮733题来源和1024回答容量，仅证据表示与生成政策改变；输入token数可能因表示而变化，真实效果等待冻结评测。
